# OTV The Menu — Concept Preview

Big Cory / OTV Agency concept site. Offers are in development. The email form is a local demonstration and does not collect or send data. No checkout is connected.

## Local preview

Run `python3 -m http.server 8867` from this directory. No installation or build is required.

## Publication

GitHub Pages should serve the `main` branch from the repository root. The site uses relative asset paths. No custom domain is configured.

## Current scope

Preserves Claude’s existing artwork, four packs, pricing, spray reveal, and pouch flips. Adds a mobile viewport, concept-preview labels, “Call the Plug” for the top package, and “The Joint” five-prompt sample description.

Detailed package revisions and additional motion remain under review. Product assets and email delivery must be completed before sales launch.
